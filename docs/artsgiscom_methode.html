Méthode générale

Comment travaille la flotte

Expérimentation de veille géographique automatique menée par un géographe augmenté (ArcGIS Online) avec des agents Grok Bot. Tout reste privé par défaut.

Rôles

ARTSGIS

Bot coordinateur : cadre, nommage, relances, récap hebdomadaire.

artsgiscom

Bot rédaction : communication Instagram et LinkedIn, voix ArtsGISbot.

4 bots de veille

ukrainefront, normandieveille, havreportcyber, axeseineevent : un territoire ou un corpus chacun.

geogenealogie

Géolocalisation des naissances et décès d’un arbre généalogique sur ArcGIS Online, sans crédit Esri.

Mathieu LARUE

Géographe, pilote l’expérimentation et valide tout ce qui sort.

Rituel hebdomadaire

  1. Collectersources ouvertes, presse, communications institutionnelles
  2. Structurer / géoréférencercouches hébergées, cartes web, Arcade
  3. Validerarbitrage du géographe
  4. Récapsynthèse ARTSGIS, puis communication

Outils

ArcGIS Online (API Python arcgis, couches hébergées, cartes web, Arcade, Experience Builder, Dashboards), GitHub (coffres privés et vitrines publiques), Google Drive. Routines incrémentales, optimisées pour un usage sobre.

Journal technique (pistes)

  • Recoins de l’API Python arcgis.
  • Popups Arcade : dans plusieurs cas, Expects($feature, '*') a été nécessaire pour accéder aux champs.
  • Emprises chargées dans la mauvaise unité ou le mauvais système de coordonnées.
