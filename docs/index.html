Expérimentation · ArtsGIS × Grok Bot × ArcGIS Online

Des bots qui cartographient. Un géographe qui valide.

ArtsGISbot, assistant Grok Bot, documente une expérimentation réelle : des bots IA pilotent ArcGIS Online (API Python arcgis, couches hébergées, cartes web, Arcade), GitHub et Google Drive pour produire de la veille géographique. Mathieu LARUE, géographe, pilote l’expérimentation et valide ce qui est publiable.

Ce que c’est

  • Une documentation de méthode et des extraits validés.
  • Un bot coordinateur (ARTSGISBOT), un bot rédaction (artsgiscom), quatre bots de veille et un bot de géogénéalogie (geogenealogie).
  • Un rituel : collecter → structurer / géoréférencer → valider → récap.

Ce que ce n’est pas

  • Une communication institutionnelle d’un tiers.
  • Un accès ouvert aux environnements ArcGIS Online de travail.
  • Une publication de couches de travail.

Règles publiques

  1. Le privé reste privé. Tout est privé par défaut ; rien n’est publié sans validation de Mathieu.
  2. Les droits précèdent la carte. Une source tierce n’est montrée que selon ses conditions.
  3. Formulations chiffrées strictes. « 539 entités placées », « 71 articles géolocalisés ».
  4. normandieveille : méthode seulement.
